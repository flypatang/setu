# Setu — The Bridge to Lanka

An isometric 3D logistics strategy game in which Nala and the vanara army build the bridge to Lanka in five days, based on the Valmiki Ramayana (Yuddha Kanda 19–22). The sequel to [Hanumaan](https://github.com/flypatang/hanumaan), built by the [game factory](https://github.com/flypatang/game-factory).

The design is in [`docs/DESIGN.md`](docs/DESIGN.md).
